【3) C6b NOTOUCH-5 断言精确描述】

Spec §4 C6 / NOTOUCH-5 invariant:
  "若 user 清空章节等于没覆盖 → baseline；空字符串 dirty 字段不得进入 payload"

实现侧（Hook generateReport 内）：
  for (const field of state.dirty) {
    if (field === "source_snapshot_id") continue;
    const val = state.draft[field];
    if (typeof val !== "string") continue;
    if (val === "") continue;  // ← NOTOUCH-5: 空字符串跳过，完全不写 key
    const overrideKey = CHAPTER_OVERRIDE_PREFIX[field];
    if (overrideKey) (payload as Record<string,string>)[overrideKey] = val;
  }

测试侧（C6 it block 内）：
  // Arrange: 3 个字段被 dirty，但 ch2_methods 值是空串
  act(() => {
    result.current.onFieldChange("ch1_background", "bg non-empty");
    result.current.onFieldChange("ch2_methods", "");     // ← dirty 但空
    result.current.onFieldChange("ch7_discussion", "discussion value");
  });

  // Act: generateReport → fetchClient.post 调用 payload 断言：
  expect(payload.override_ch1_background).toBe("bg non-empty");    // ✓ 传了
  expect(payload.override_ch7_discussion).toBe("discussion value"); // ✓ 传了
  expect(
    Object.prototype.hasOwnProperty.call(payload, "override_ch2_methods")
  ).toBe(false);  // ✓ NOTOUCH-5: 空串 dirty 字段，**完全不传该 key**
                  //   (不是传空字符串 ""，是 payload 对象上根本没有这个属性)
