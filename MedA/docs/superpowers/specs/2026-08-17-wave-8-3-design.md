## 3. 5 表数据模型（L3）+ 2 RULES（双校验）

### 3.1 5 个 SQLModel 表定义

```python
# ExtractionTemplate（每个 project 有 0 or 1 份 locked template）
class ExtractionTemplate(SQLModel, table=True):
    id: int | None = Field(default=None, primary_key=True)
    project_id: int = Field(foreign_key="researchproject.id", index=True)
    name: str = Field(max_length=200)
    fields_json: list[dict] = Field(default=[], sa_column=sa.Column(sa.JSON))
    # fields_json[i] = {
    #   key:str (unique per template), label:str,
    #   type ∈ {text,number,select,date,categorical},
    #   options: list[str]? (for select/categorical),
    #   pico_binding ∈ {P,I,C,O,S,StudyType,OutcomeMeasure,Other},
    #   required: bool, description: str?, help: str?
    # }
    created_at: datetime = Field(default_factory=utc_now)
    locked: bool = False
    locked_at: datetime | None = None
    created_by_user_id: int | None = None

# ExtractionCell（EAV 长表结构：(record_id, field_key, reviewer_id) = PK）
class ExtractionCell(SQLModel, table=True):
    record_id: int = Field(foreign_key="literaturelibraryrecord.id", primary_key=True)
    field_key: str = Field(max_length=100, primary_key=True)
    reviewer_id: int = Field(primary_key=True)
    value_json: Any | None = Field(sa_column=sa.Column(sa.JSON))
    confidence: float | None = Field(default=None, ge=0.0, le=1.0)
    extracted_at: datetime = Field(default_factory=utc_now)

# OutcomeDefinition
class OutcomeDefinition(SQLModel, table=True):
    id: int | None = Field(default=None, primary_key=True)
    project_id: int = Field(foreign_key="researchproject.id", index=True)
    name: str = Field(max_length=300)
    outcome_type: str = Field(pattern=r"^(binary|continuous)$")
    measure: str = Field(pattern=r"^(RR|OR|RD|MD|SMD)$")
    time_point: str | None = Field(default=None, max_length=200)
    description: str | None = None
    created_at: datetime = Field(default_factory=utc_now)

# OutcomeArmData（每 outcome 每 study 的 2 个 arms：干预 + 对照）
class OutcomeArmData(SQLModel, table=True):
    id: int | None = Field(default=None, primary_key=True)
    outcome_id: int = Field(foreign_key="outcomedefinition.id", index=True)
    record_id: int = Field(foreign_key="literaturelibraryrecord.id", index=True)
    arm_label: str = Field(max_length=100)  # "intervention" / "control" / free
    # Binary outcome
    events: int | None = Field(default=None, ge=0)
    n_total: int | None = Field(default=None, ge=1)
    # Continuous outcome
    mean_val: float | None = None
    sd_val: float | None = Field(default=None, ge=0)
    n_continuous: int | None = Field(default=None, ge=1)

# AnalysisRun（缓存 meta 结果避免重算，幂等）
class AnalysisRun(SQLModel, table=True):
    id: int | None = Field(default=None, primary_key=True)
    project_id: int = Field(index=True)
    outcome_id: int = Field(foreign_key="outcomedefinition.id", index=True)
    analysis_model: str = Field(pattern=r"^(fixed_iv|fixed_mh|random_dl)$")
    run_at: datetime = Field(default_factory=utc_now)
    result_json: dict = Field(default={}, sa_column=sa.Column(sa.JSON))
    # result_json keys:
    #   { studies:[{study_label,effect,ci_low,ci_high,weight,events1,n1,events2,n2}],
    #     pooled:{effect,ci_low,ci_high,z_stat,p_value,model},
    #     heterogeneity:{Q,df_Q,p_Q,I2_pct,tau2},
    #     meta:{k_studies,total_n} }
```

### 3.2 RULES EX1-EX8（双校验：service 层 + endpoint 层；非法一律 422 整体 ROLLBACK）

| RULE ID | 合法条件 | 非法 422 detail 字面量（严格固定）|
|---|---|---|
| EX1 | Template `locked=True` 时：**fields_json / name 不允许改任何字段**（description/help 仍可改）| `"template_locked_cannot_change_fields"` |
| EX2 | ExtractionCell upsert 时：对应 LiteratureLibraryRecord 必须 `decision="included" AND screening_stage="fulltext"`（只允许在 N4 纳入文献抽取）| `"record_not_in_included_n4"` |
| EX3 | POST OutcomeArmData 到 outcome_type=binary：**mean_val/sd_val 必须是 None**（不能同时给 continuous 数据）| `"outcome_type_mismatch_expected_binary_arms"` |
| EX4 | POST OutcomeArmData 到 outcome_type=continuous：**events/n_total 必须是 None** | `"outcome_type_mismatch_expected_continuous"` |
| EX5 | POST run-meta：**参与 Meta 的 study 数量 k ≥ 2** | `"meta_requires_at_least_2_studies"` |
| EX6 | Binary 2×2：`0 ≤ events ≤ n_total`；若 events 或 n_total 任一缺失则跳过该 study（不报错，不计入 k）；若两个 arm 都缺则 skip | `"2x2_events_gt_total_n_invalid"`（仅当 events>n_total 时触发）|
| EX7 | Continuous：`sd_val > 0 且 n_continuous ≥ 2` | `"continuous_sd_or_n_invalid_nonpositive"` |
| EX8 | Pooled 加权后 Σwi = 0（例如所有 SEi=inf）| `"zero_total_weight_cannot_compute_pooled"` |

### 4.2 9 公式伪代码（核心部分）

```
S1 正态 CDF Φ(x):
  math.erfc 精确实现 → Φ(x) = 0.5 * erfc(-x/√2)；定义域 x ∈ [-37, 37] 之外截断 0/1

S2 log(RR) = log(a/n1 / (c/n2))
   SE(logRR) = sqrt(1/a - 1/n1 + 1/c - 1/n2)      （含 a=0 或 c=0 → 0.5 连续性校正（0.5 加到 4 cells，若任一为空））
   95%CI = exp(logRR ± 1.96 * SE)
   z = logRR / SE
   p = 2 * Φ(-|z|)

S3 log(OR) = log(a*d / (b*c))    ; b = n1-a ; d = n2-c
   SE(logOR) = sqrt(1/a + 1/b + 1/c + 1/d)        （连续性校正 0.5 同上）

S4 RD = a/n1 - c/n2
   SE(RD) = sqrt(a*(n1-a)/n1^3 + c*(n2-c)/n2^3)

S5 MD = m1 - m2 （continuous）
   sp² = ((n1-1)*s1² + (n2-1)*s2²) / (n1+n2-2)
   SE(MD) = sqrt(sp² * (1/n1 + 1/n2))

S6 Fixed Inverse-Variance weights:
   wi = 1 / SEi²
   θpooled_IV = Σ wi θi / Σ wi
   SE_pooled_IV = 1 / sqrt(Σ wi)
   Q = Σ wi (θi - θpooled_IV)²    （用 IV pooled 算 Q）
   I²_pct = max(0, (Q - (K-1)) / Q * 100)   （若 Q ≤ K-1 → I²=0）

S7 Fixed Mantel-Haenszel（仅 binary）:
   RR_MH = Σ( (a_i * n2_i / N_i) ) / Σ( (c_i * n1_i / N_i) )    ; N_i = n1_i + n2_i
   OR_MH = Σ( (a_i d_i / N_i) ) / Σ( (b_i c_i / N_i) )
   RD_MH = Σ( (a_i * n2_i - b_i * c_i) / N_i² * N_i ) / Σ( n1_i n2_i / N_i² ) （经典 MH RD）

S8 DerSimonian-Laird Random effects:
   τ²_DL = max(0, (Q - (K-1)) / (Σwi - Σwi²/Σwi) )
   w_rand_i = 1 / (SEi² + τ²_DL)
   θpooled_RAND = Σ w_rand_i θi / Σ w_rand_i
   SE_RAND = 1 / sqrt(Σ w_rand_i)

S9 卡方分布 CDF（χ²） → 正则化不完全 gamma P(a,x)（低阶 Gamma）:
   df = K-1;  a = df/2; x = Q/2
   用级数展开 γ(a,x) = Σ_{n=0}^{∞} x^a e^{-x} x^n / (a (a+1) ... (a+n)) 前 200 项；
   p_Q = 1 - P(df/2, Q/2)
```

### 4.3 Cohen Kappa（2×2 或 N×N 通用）

```
po = Σ diag_ii / N
pe = Σ (row_i_total * col_i_total) / N²
Kappa = (po - pe) / (1 - pe)
（若 1-pe = 0 → Kappa = NaN，AC1 golden 不会触发该 edge case）
```
