# MedA Wave 3 项目工作台设计文档

> 设计日期：2026-08-04
> 设计范围：项目工作台信息架构 + Hermes 视觉复刻第一批页面
> 适用阶段：Wave 3 设计确认

## 1. 设计目标

本设计文档用于定义 MedA 在 `Wave 3` 阶段的项目工作台方案。该阶段不追求一次性铺完全部科研模块，而是先把用户登录后真正进入的工作台主链路做实，并在视觉与交互上尽量贴近参考系统 `Hermes`。

本阶段的核心目标有三项：

- 固化登录后首页的信息架构与页面骨架
- 以 `Hermes` 保守复刻为主，先把工作台壳层、导航层级和专业工作区气质做出来
- 在不破坏 `Hermes` 工作台结构的前提下，将 MedA 的科研流程能力显性嵌入首页

## 2. 已确认设计决策

- `Wave 3` 的目标对象是“项目工作台第一批页面”，不是全量科研模块深度实现
- 工作台首页采用 `三栏工作台` 骨架，而非纯仪表盘或纯流程页
- 中间主区采用 `C1 混合首页` 结构
- 右侧栏第一屏优先承载 `助手 + 待办`
- 整体设计路线采用 `Hermes 保守复刻`
- Web 与 Desktop 共享同一信息架构，只允许宿主能力差异，不允许页面语义分叉

## 3. 方案取舍结论

### 3.1 首页骨架取舍

本轮评估过三种首页骨架：

- `A. 三栏工作台`
- `B. 总览仪表盘`
- `C. 流程看板`

最终采用 `A. 三栏工作台`，原因如下：

- 最贴近成熟专业工作台形态，便于承接 `Hermes` 的视觉和交互风格
- 能同时容纳项目导航、工作主区、助手侧栏三种职责
- 既适合工作继续流，也为后续 MedA 科研 Agent 能力预留了稳定挂载位

### 3.2 中间主区取舍

本轮评估过三种中间主区首页方案：

- `A1. 项目总览优先`
- `B1. 当前任务优先`
- `C1. 混合首页`

最终采用 `C1. 混合首页`，原因如下：

- 保留了 `Hermes` 工作台首页的专业入口感
- 避免首页退化成纯管理 dashboard
- 能把 MedA 的科研流程卡片显性嵌入首页，而不把首页做成单一流程页
- 同时满足“现在在哪”和“下一步做什么”两个核心问题

### 3.3 右侧栏取舍

右侧栏优先承载 `助手 + 待办`，不以项目统计、重表格或长文阅读为主。这样可以保证右侧栏成为推进工作与即时反馈区域，而不是第二个主内容区。

## 4. 总体设计原则

- `Hermes` 视觉优先：布局、分区、密度和操作节奏先尽量贴近参考系统
- MedA 能力显性嵌入：科研流程要在首页可见，但不破坏工作台骨架
- 首页服务于继续工作：首页首先回答“当前项目进行到哪”和“接下来做什么”
- 项目上下文统一：所有模块、任务、产物、助手都围绕 `ResearchProject` 运转
- 双端一致优先：Web 与 Desktop 保持一致的信息架构和业务含义
- 可追溯优先：首页上出现的任务、产物、提醒都必须能跳转到可追溯详情

## 5. 首页信息架构

工作台首页采用四段式结构：

1. `左侧窄导航`
2. `左侧次级面板`
3. `中间主区`
4. `右侧栏`

### 5.1 左侧窄导航

左侧窄导航承担全局主模块切换，不承载项目细节。建议固定入口如下：

- 工作台
- 项目
- 数据 / 资料
- Agent
- 产物
- 管理

交互规则：

- 一级导航只负责大模块切换
- 当前模块必须有明确激活态
- Web 与 Desktop 保持同一顺序、同一命名、同一图标语义

### 5.2 左侧次级面板

左侧次级面板承担当前项目上下文展示与快捷入口职责。首页下优先展示：

- 当前项目名称
- 项目标识编号
- 所属机构
- 当前阶段
- 项目切换入口
- 模块快捷入口，如研究设计、文献检索、数据抽取、结果分析、报告生成

交互规则：

- 项目切换路径必须短，不能迫使用户离开工作台深跳
- 快捷入口进入具体页面，不在首页内展开复杂编辑
- 次级面板负责“我现在在哪个项目”，不负责承载大块动态内容

### 5.3 中间主区

中间主区采用 `C1 混合首页`，分三层：

#### 顶部摘要层

用于概括当前项目状态，并给出唯一主操作入口。建议包含：

- 项目标题
- 当前阶段
- 阶段进度
- 最近更新时间
- 负责人或最近协作状态
- 一个主 CTA，例如“继续上次研究”或“进入当前阶段”

约束：

- 主 CTA 默认只保留一个，避免首页操作过散
- 摘要层是首页视觉焦点，但不承担重编辑功能

#### 中段流程层

用于显性表达 MedA 的科研流程主链路，建议以 5 至 7 个阶段卡片组织，例如：

- 选题
- 检索
- 筛选
- 抽取
- 分析
- 产出

每个阶段卡片至少包含：

- 阶段名称
- 当前状态
- 最近任务数或产物数
- 进入按钮

交互规则：

- 卡片点击后进入对应模块页
- 首页只展示阶段摘要，不在此处展开复杂工作区
- 卡片状态需要和真实后端项目状态保持同步

#### 下段活动层

用于承接近期可继续工作的对象，建议拆为两块或三块：

- 最近任务
- 最近产物
- 协作 / 系统动态

交互规则：

- 点击最近任务应直接续做
- 点击最近产物应进入版本或详情页
- 动态信息以短摘要为主，不在首页展开长日志

### 5.4 右侧栏

右侧栏在第一屏固定为上下两段：

#### 上段：Agent 助手

展示：

- 当前建议动作
- 一键快捷操作
- 上次对话或最近调用入口

#### 下段：待办与提醒

展示：

- 待处理任务
- 审批或异常提醒
- 截止时间临近事项

交互规则：

- 右栏内容必须短、快、可执行
- 不放长文本说明，不放重表格
- 右栏触发动作后，主内容仍在中间主区展开

## 6. 关键交互规则

### 6.1 首页回答的两个核心问题

首页进入后必须在第一屏清楚回答：

- `现在在哪`
- `下一步做什么`

如果某项信息不能服务于这两个问题，就不应占用首页核心区域。

### 6.2 首页不承载重编辑

首页只展示摘要、入口和状态，不直接承担以下内容：

- 大体量编辑器
- 重分析表格
- 全屏配置面板
- 长文本报告编辑工作区

这些内容应进入对应模块页承载。

### 6.3 首页跳转闭环

Wave 3 首页必须打通以下真实链路：

- 首页主 CTA -> 当前阶段页
- 阶段卡片 -> 对应科研模块入口页
- 最近任务 -> 任务详情或续做页
- 最近产物 -> 产物详情或版本页
- 右侧助手动作 -> 对应工作流触发页或会话面板

### 6.4 项目上下文一致性

首页、中间模块页、右侧助手、最近产物页必须共享同一 `ResearchProject` 上下文。任何跳转都不能丢失项目语义，也不能退化回单纯聊天上下文。

## 7. Wave 3 第一批页面清单

Wave 3 只实现第一批最关键页面，保证“工作台主链路”成立。

### 7.1 必做页面

1. `项目工作台首页`
   - 三栏工作台
   - `C1` 混合首页
   - 右侧助手 + 待办

2. `项目切换 / 项目概览承接层`
   - 以左侧次级面板和必要浮层承载
   - 支持快速切项目、看项目摘要

3. `科研流程模块入口页`
   - 由首页阶段卡片进入
   - 先完成入口层与导航闭环，不在本波展开全部深业务能力

4. `最近任务承接页`
   - 至少支持从首页续做任务

5. `最近产物承接页`
   - 至少支持查看最近产物和版本入口

6. `右侧助手触发面板`
   - 先完成轻量交互壳层
   - 为后续科研 Agent 深能力预留位置

### 7.2 明确不在本波完成的内容

- 全部科研模块的深度业务页
- 完整管理员后台扩展
- 复杂数据驾驶舱
- 首页内重编辑和重分析工作区
- 全量 `Hermes` 页面 1:1 完整复刻

## 8. 双端一致性约束

- Web 与 Desktop 使用同一业务 API、同一项目状态、同一导航语义
- 双端允许在窗口控制、快捷键、本地桥接、通知方式上存在宿主差异
- 双端不允许出现不同的信息架构定义
- 同一页面在双端只能做容器适配，不改模块职责和内容优先级

## 9. Wave 3 交付边界

Wave 3 的交付目标是打通以下链路：

`登录态 -> 项目工作台首页 -> 项目上下文切换 -> 科研流程入口 -> 最近任务/产物承接 -> 右侧助手/待办联动`

只要该链路跑通，后续 `Wave 4` 起即可围绕既定骨架逐批扩展 `Hermes` 复刻页面和 MedA 科研模块。

## 10. 验收标准

Wave 3 完成后，至少应满足以下标准：

- 用户登录后可进入统一的项目工作台首页
- Web 与 Desktop 呈现一致的工作台信息架构
- 首页布局符合 `Hermes` 风格的专业工作台气质
- 首页中段能清晰表达 MedA 科研流程阶段
- 最近任务、最近产物、右侧助手动作均可真实跳转
- 页面中的项目、任务、产物和提醒都能定位到统一项目上下文

## 11. 风险与控制点

- 如果首页承载过多统计模块，容易偏成管理 dashboard，削弱工作台连续性
- 如果流程卡片做得过重，首页会退化成单一流程页，削弱平台入口泛化能力
- 如果右侧栏承载过多内容，会和中间主区竞争视觉焦点
- 如果双端分别做页面裁剪，后续会破坏统一设计和统一实现成本

控制策略：

- 首页坚持摘要与入口优先
- 工作流深内容下沉到模块页
- 右侧栏只做轻量推进区
- 双端共用同一页面定义与状态语义

## 12. 设计结论

MedA `Wave 3` 项目工作台应采用 `Hermes 保守复刻` 路线，在三栏工作台骨架下落地 `C1 混合首页`，并将右侧栏固定为 `助手 + 待办`。本波以首页、项目切换承接层、科研流程入口页、最近任务/产物承接页、右侧助手壳层为第一批页面范围，优先完成工作台主链路闭环，为后续分波扩展 `Hermes` 复刻页面与 MedA 科研业务模块打基础。
