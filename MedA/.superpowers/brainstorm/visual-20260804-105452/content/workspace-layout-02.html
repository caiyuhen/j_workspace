A 方案继续细化：中间主区第一屏放什么

左导航 + 中主区 + 右侧助手已经定了。现在只决定首页进入后，用户第一眼看到的是哪一类核心信息。

Recommended: C

A1. 项目总览优先

先展示项目摘要、关键指标、近期动态，再进入具体任务。稳，但会更像 dashboard。

优点是管理感强，缺点是“下一步做什么”不够直接。

B1. 当前任务优先

首页直达“继续上次工作”“待办队列”“最新产物”，操作效率最高。

优点是强执行流，缺点是项目全貌会被压缩到次级区域。

C1. 混合首页

顶部放项目总状态与主 CTA，中段直接给科研流程阶段卡片，下段放最近任务/产物/协作动态。

最平衡，既保留 Hermes 式工作台入口，又把 MedA 的科研流程显性化。
