Wave 3: 项目工作台第一屏结构

我们先只定首页骨架。目标是既能贴近 Hermes 的专业工作台气质，又要能承接科研全流程模块。

Recommended: A

A. 三栏工作台

左侧项目导航，中间主工作流，右侧助手/状态/待办。最像成熟的专业工作台，也最容易承接后续科研 Agent 面板。

适合把“项目切换 + 当前任务 + Agent 协同 + 审计状态”同时放在首屏。

B. 总览仪表盘

先看项目 KPI、告警、里程碑，再进入具体模块。信息密度高，适合管理视角，但工作流连续性稍弱。

适合“管理驾驶舱”优先的首页，但离 Hermes 式操作台会更远一点。

C. 流程看板

首页直接进入“选题-检索-抽取-分析-产出”的科研流程推进视角，右侧是当前阶段详情。

很适合 MedA 专属流程，但作为整个平台统一入口，泛化能力会弱一些。
