PRD 9 · §4 Wave 9c · Abstractor Auto-Triager

SimHash + Jaccard 去重 → LLM 结构化摘要（PICO 提取）→ 3 档 triage（Include/Exclude/Review）+ 置信度分 + 可解释理由 → 推荐动作（evidence_artifact stage=data_abstractor）

Abstractor 三步流水线（顺序不可逆，耗时 ~ 6s/篇）

3-Stage Abstractor Pipeline · 可开关纯规则 / LLM
1
SimHash + Jaccard 跨库去重
纯算法 · ~ 20ms/篇 · 0 成本
算法细节（0 第三方依赖）：
  • 64-bit SimHash：标题+摘要关键词 2-shingle
  • 阈值 ≤ 7 bits Hamming + DOI/PMID 完全匹配
  • Jaccard 相似度 ≥ 0.92 标题或摘要重合
  • 输出 duplicate_cluster_id + 保留 最长随访期 主记录
示例输出： PubMed ID 38924711 和 Embase ID 24-88712 → Hamming 4 bits + 共 89% Jaccard → 合并为 Cluster C-8842，主记录 Embase（随访 52w vs PubMed 摘要 24w）
→
2
LLM 结构化 PICO 摘要
~ 5s/篇 · ~ 0.01$/篇（GPT-4o-mini）
Prompt 固定模板（Cochrane PICO 标准）
输出 JSON：{
 "p": {text, n, condition, age_min, age_max},
 "i": {drug, dose, duration, n},
 "c": {comparator, type},
 "o": [{name, mean_diff, rr, ci_low, ci_high, p_value}]
}
失败保护：LLM JSON 解析失败 2 次 → 自动降级为"只做标题 PICO 关键词匹配"，triage=Review（不冒错排风险）
→
3
Rule-Based Triage 3 档
纯规则 · 可审计 · 可解释
IF-THEN 规则表（可编辑）：
✅ Include: P∩I∩C∩O 全匹配 & RR 点估计落在 benefit 区间
⚠️ Review: 任意一项缺失 或 PICO 模糊（如"糖尿病"未分 T1/T2）
❌ Exclude: ① 研究类型错 ② 人群错 ③ 干预完全无关 ④ 结局完全不相关
置信度公式：
confidence = 0.7·PICO_match + 0.2·study_type + 0.1·outcome_quality
≥ 0.85 Include | 0.45-0.85 Review | < 0.45 Exclude
