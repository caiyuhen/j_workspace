# 医学风险分析报告

## 概述

本报告基于血管功能分析数据，结合医学逻辑与算法逻辑，对心梗和脑卒中风险进行综合评估。分析涵盖未来7日和30日的风险程度与概率值。

## 分析方法论

### 1. 风险评估维度

#### 心梗风险评估维度
- **血管功能** (权重: 25%): PWV、血管年龄、AIx、心率变异性
- **心律失常** (权重: 20%): 房颤、室早、房早检出率
- **炎症指标** (权重: 20%): 炎症评分、HRV、灌注指数
- **血流动力学** (权重: 15%): 血管阻力、血流速度、灌注状态
- **睡眠呼吸暂停** (权重: 10%): AHI指数、SpO2水平
- **血压变异性** (权重: 10%): 血压变异系数、昼夜节律

#### 脑卒中风险评估维度
- **血管功能** (权重: 30%): 更重视血管状态
- **心律失常** (权重: 25%): 房颤是脑卒中重要因素
- **炎症指标** (权重: 15%): 炎症与脑血管病变相关
- **血流动力学** (权重: 15%): 脑血流灌注评估
- **血压变异性** (权重: 15%): 血压波动对脑血管影响显著

### 2. 特征值计算方法

#### 血管功能风险评分
```
PWV风险评分:
- PWV > 12 m/s: +25分 (显著升高)
- PWV > 10 m/s: +15分 (轻度升高)

血管年龄风险评分:
- 血管年龄 > 80岁: +20分 (显著老化)
- 血管年龄 > 70岁: +12分 (轻度老化)

AIx风险评分:
- AIx > 30%: +15分 (动脉硬化显著)
- AIx > 20%: +8分 (动脉硬化轻度)

LF/HF比值风险评分:
- LF/HF > 4: +10分 (自主神经失衡)
- LF/HF > 2.5: +5分 (自主神经轻度异常)
```

#### 心律失常风险评分
```
房颤检出率:
- >10%: +40分 (高风险)
- 5-10%: +25分 (中等风险)
- >0%: +10分 (偶发)

室性早搏检出率:
- >10%: +20分 (频发)
- 5-10%: +10分 (中等)

房性早搏检出率:
- >10%: +15分 (频发)
- 5-10%: +8分 (中等)

正常心律比例:
- <80%: +15分 (正常心律比例低)
```

#### 炎症风险评分
```
炎症评分:
- >4分: +25分 (高炎症)
- >3分: +15分 (中等炎症)

中度炎症比例:
- >50%: +15分 (中度炎症比例高)

RMSSD (心率变异性):
- <20ms: +20分 (显著降低)
- <30ms: +10分 (轻度降低)

灌注指数:
- <2: +15分 (灌注不足)
```

#### 血流动力学风险评分
```
血管阻力:
- >10: +20分 (显著增高)
- >5: +10分 (轻度增高)

血流速度:
- <5: +15分 (血流速度降低)

灌注指数:
- <2: +15分 (灌注降低)
- >10: +10分 (灌注异常升高)

低灌注比例:
- >30%: +25分 (低灌注比例高)
- >10%: +15分 (低灌注比例中等)
```

#### 睡眠呼吸暂停风险评分
```
AHI指数:
- ≥30: +30分 (重度)
- ≥15: +20分 (中度)
- ≥5: +10分 (轻度)

最低SpO2:
- <85%: +20分 (严重低氧)
- <90%: +15分 (中度低氧)

SpO2<90%时间比例:
- >5%: +15分 (低氧时间比例高)
```

#### 血压变异性风险评分
```
血压变异系数:
- >20%: +25分 (显著增高)
- >15%: +15分 (轻度增高)

昼夜节律模式:
- 反杓型: +20分
- 非杓型: +15分
- 杓型异常: +10分
```

### 3. 风险概率计算

使用Logistic回归模型计算风险概率:

```
心梗风险概率 = 1 / (1 + exp(-(风险评分 - 50) / 15))
脑卒中风险概率 = 1 / (1 + exp(-(风险评分 - 45) / 18))
```

### 4. 时间因子调整

- **7日风险**: 基础评分 × 1.0
- **30日风险**: 基础评分 × 1.3 (心梗) / 1.25 (脑卒中)

### 5. 风险等级划分

| 风险等级 | 评分范围 | 描述 |
|---------|---------|------|
| 低风险 | 0-29分 | 风险较低，建议定期监测 |
| 中等风险 | 30-59分 | 需要关注，建议专科检查 |
| 高风险 | 60-79分 | 高风险，建议立即就医 |
| 极高风险 | 80-100分 | 极高风险，需要紧急医疗干预 |
