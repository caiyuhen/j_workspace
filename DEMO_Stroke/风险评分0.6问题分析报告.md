# 风险评分集中在0.6左右的原因分析报告

## 问题描述
通过分析36个设备的风险评估结果，发现心梗风险评分集中在0.618-0.654范围内（均值0.623），脑卒中风险评分集中在0.604-0.724范围内（均值0.675），都围绕0.6左右。

## 根本原因分析

### 1. 风险因子评分分布问题

通过对原始血管分析数据的深入分析，发现以下关键问题：

#### 主要风险因子评分分布：
- **PWV脉搏波速度**: 均值=1.000 (所有样本都是最高风险)
- **血管年龄**: 均值=0.740 (大部分为高风险)
- **心率变异性**: 均值=0.700 (所有样本都是固定高风险)
- **血压昼夜节律**: 均值=0.920 (大部分为最高风险)
- **炎症指标**: 均值=0.500 (所有样本都是中等风险)
- **血压变异性**: 均值=0.600 (所有样本都是固定风险)

#### 低风险因子：
- **睡眠呼吸暂停**: 均值=0.000 (所有样本都是低风险)
- **心律失常**: 均值=0.000 (所有样本都是低风险)
- **血氧饱和度**: 均值=0.240 (大部分为低风险)

### 2. 权重配置导致的集中效应

#### 心梗风险权重分析：
```
PWV (1.000) × 0.220 = 0.220
血管年龄 (0.740) × 0.150 = 0.111
HRV (0.700) × 0.180 = 0.126
炎症 (0.500) × 0.160 = 0.080
血压变异性 (0.600) × 0.120 = 0.072
睡眠呼吸暂停 (0.000) × 0.110 = 0.000
血氧饱和度 (0.240) × 0.060 = 0.014
总计 ≈ 0.623
```

#### 脑卒中风险权重分析：
```
血压昼夜节律 (0.920) × 0.240 = 0.221
PWV (1.000) × 0.180 = 0.180
血压变异性 (0.600) × 0.160 = 0.096
血管年龄 (0.740) × 0.140 = 0.104
炎症 (0.500) × 0.120 = 0.060
心律失常 (0.000) × 0.100 = 0.000
血氧饱和度 (0.240) × 0.060 = 0.014
总计 ≈ 0.675
```

### 3. 具体问题分析

#### 问题1：PWV评分算法过于严格
```python
# 当前PWV评分逻辑
if mean_pwv < 7:
    return 0.0      # 正常
elif mean_pwv < 10:
    return 0.3      # 轻度升高
elif mean_pwv < 12:
    return 0.6      # 中度升高
elif mean_pwv < 15:
    return 0.8      # 重度升高
else:
    return 1.0      # 极重度升高
```
**问题**: 实际数据中PWV均值为20.0 m/s，远超15，导致所有样本都被评为1.0（极重度升高）

#### 问题2：HRV评分逻辑问题
```python
# 当前HRV评分逻辑
if 0.5 <= mean_lf_hf <= 2.0:
    return 0.0      # 正常
elif mean_lf_hf < 0.5:
    return 0.7      # 副交感神经过度激活
```
**问题**: 实际数据中LF/HF比值均值为0.075，远小于0.5，导致所有样本都被评为0.7

#### 问题3：血管年龄评分阈值设置
```python
# 当前血管年龄评分逻辑
if mean_age < 40:
    return 0.0
elif mean_age < 50:
    return 0.2
elif mean_age < 60:
    return 0.4
elif mean_age < 70:
    return 0.6
elif mean_age < 80:
    return 0.8
else:
    return 1.0
```
**问题**: 实际数据中血管年龄均值为74.8岁，大部分样本都在70-80岁区间，导致评分集中在0.8

#### 问题4：固定评分导致缺乏区分度
- 炎症指标：所有样本都是"moderate"级别，评分固定为0.5
- 血压变异性：所有样本评分都是0.6
- 睡眠呼吸暂停：所有样本评分都是0.0
- 心律失常：所有样本评分都是0.0

### 4. 数据质量问题

#### 数据分布异常：
1. **PWV数据异常**: 所有样本PWV都是20.0 m/s，缺乏变异性
2. **HRV数据偏低**: LF/HF比值普遍过低（0.075 vs 正常范围0.5-2.0）
3. **血管年龄偏高**: 平均74.8岁，可能存在系统性偏差
4. **某些指标缺失**: 睡眠呼吸暂停和心律失常数据可能不完整

## 解决方案建议

### 1. 调整评分阈值
```python
# 建议的PWV评分调整
if mean_pwv < 10:
    return 0.0      # 正常
elif mean_pwv < 15:
    return 0.3      # 轻度升高
elif mean_pwv < 20:
    return 0.6      # 中度升高
elif mean_pwv < 25:
    return 0.8      # 重度升高
else:
    return 1.0      # 极重度升高
```

### 2. 优化HRV评分逻辑
```python
# 建议的HRV评分调整
if 0.5 <= mean_lf_hf <= 2.0:
    return 0.0      # 正常
elif 0.1 <= mean_lf_hf < 0.5:
    return 0.4      # 轻度异常
elif mean_lf_hf < 0.1:
    return 0.7      # 重度异常
elif mean_lf_hf < 3.0:
    return 0.4      # 轻度交感神经激活
else:
    return 0.8      # 重度交感神经激活
```

### 3. 重新校准权重
考虑降低PWV和HRV的权重，增加其他有区分度指标的权重。

### 4. 数据质量改进
1. 检查PWV测量算法，确保数据变异性
2. 验证HRV计算方法
3. 完善睡眠呼吸暂停和心律失常检测

## 总结

风险评分集中在0.6左右的主要原因是：
1. **评分阈值设置不当**：PWV、HRV等关键指标的阈值与实际数据分布不匹配
2. **数据缺乏区分度**：多个风险因子评分固定或变异性极小
3. **权重配置问题**：高权重因子（PWV、HRV）评分过于集中
4. **数据质量问题**：某些生理指标可能存在测量或计算偏差

建议优先调整评分阈值和权重配置，以提高风险评估的区分度和准确性。
