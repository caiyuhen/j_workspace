# Medical RAG 核心机制解析：轻量级知识图谱与 Embedding 模型

本项目在知识结构化与语义向量化方面做出了底层的架构创新。系统摒弃了外部独立图数据库（如 Neo4j）和通用预训练模型的黑盒调用，转而设计了 **“Graph-in-Vector” 轻量级知识图谱**，并基于**无监督 TSDAE 机制深度微调了 Embedding 模型**。

以下是具体的底层机制解析：

---

## 1. 轻量级知识图谱 (Graph-in-Vector 架构)

为了保证数据查询的一致性与高并发性能，项目没有维护一套与向量库割裂的复杂图谱 Schema，而是将“图计算”逻辑完全降级并内嵌到了 Milvus 向量数据库的标量字段中。

### 1.1 节点即标量字段 (Entities as Tags)
在数据处理阶段，文档被切片后，会执行严格的命名实体识别（NER）。系统会从非结构化文本中拆解出多维标准化标签，如：
- **疾病节点**：`diagnoses`（如“非小细胞肺癌”）
- **药物节点**：`western_medicines`（如“吉非替尼”）
- **基因节点**：`gene_mutations`（如“EGFR 19-del”）
- **属性节点**：`stages`（如“IV期”）

这些实体列表被作为标量字段（Scalar Fields）与 512 维稠密向量严格绑定，存储在同一个 Milvus 集合 (`medical_rag`) 中。

### 1.2 边即隐式共现 (Implicit Edges)
系统不显式存储连线关系。如果“肺癌”和“奥希替尼”出现在同一个向量切片的元数据中，这种**物理共现分布**在底层逻辑上就等同于它们之间存在隐式关联（边）。这种设计完全忠于真实文档的离散分布，避免了人工画线带来的主观偏差和“图谱幻觉”。

### 1.3 混合检索与图谱定界 (Hybrid Filtering)
检索时，系统会生成底层的逻辑表达式进行标量过滤。例如，当查询特定药物疗效时，系统构建类似 SQL 的表达式：
`expr = "western_medicines like '%吉非替尼%' && diagnoses like '%肺癌%'"`

这种结构化过滤作为向量相似度计算的前置条件，能直接切断无关子图的干扰，大幅缩小搜索空间（Search Space），确保大模型不会拿到其他突变或癌症的上下文而产生医疗幻觉。

### 1.4 隐式多跳推理 (Implicit Multi-hop)
对于复杂推理，系统通过真实数据的共现性进行多跳挖掘：
1. 向量检索命中包含“EGFR突变”的切片。
2. 从这些切片的标量字段中聚合出高频共现的药物（如“奥希替尼”）。
3. 自动以该药物作为新实体，发起下一轮深度向量检索。

### 1.5 架构优势总结
1. **单点真实（Single Source of Truth）**：不需要在两个数据库之间做分布式事务，文档、向量、图谱节点全在 Milvus 的同一行数据里，数据一致性是 100% 的。
2. **避免人为图谱幻觉**：依靠底层数据的真实物理共现来判定关联，不臆造任何不存在的连线。
3. **极高的检索性能**：用向量库自带的标量倒排索引去“切图”，再算距离，比在庞大的 Neo4j 网络里做多跳遍历（Multi-hop traversal）要快得多。

---

## 2. Embedding 模型微调管线 (TSDAE Pipeline)

为了让向量捕获真实的医疗上下文而非仅仅字面匹配，项目采用本地化的私有模型训练链路。

### 2.1 基座与归一化设计
基座模型选用 `BAAI/bge-small-zh-v1.5`。在输出时，统一生成 512 维稠密向量，并强制经过 **L2 归一化 (L2 Normalization)**。这使得向量在 Milvus 中通过内积（IP, Dot Product）计算的得分等价于余弦相似度，避免了复杂的距离转换。

### 2.2 TSDAE 无监督对比学习
由于医疗领域严重缺乏高质量的“Query-Document”人工标注对，项目采用了 **TSDAE (Transformer-based Denoising AutoEncoder)** 无监督领域自适应架构：
- **原理**：对输入的私有医学文本注入**删除噪声 (Deletion Noise)**，迫使 Encoder (基于 BERT) 跨越残缺词汇去学习深层的医疗语义表征；Decoder 则利用该表征尝试还原无噪的原始文本。
- **Loss 函数**：通过 `DenoisingAutoEncoderLoss` 进行梯度更新。模型被逼迫理解“为什么这几个词会同时出现”，从而有效捕捉到医学概念间的内在逻辑关系。

### 2.3 动态切片策略 (Chunking Strategy)
- **训练期**：切片被限制在 `Chunk Size = 384`，且强制剔除长度 < 50 字符的碎片，迫使模型在有限长度内高强度拟合句子级语义。
- **推理/入库期**：将 `Chunk Size` 放宽至 `512`（Overlap = 50），以确保向大模型（LLM）喂入的上下文具有完整的段落连贯性。

### 2.4 底层索引配置
所有的 512 维向量全部灌入 Milvus，摒弃所有脱离实际的 Mock 向量或静默降级机制。索引采用 `IVF_FLAT` (`nlist=1024`, `nprobe=16`)，拒绝使用破坏数据完整性的近似压缩算法（如 PQ），确保找出的每一个 Top-K 结果都在数学上绝对准确。
