# 模型算法说明

## 任务定义
输入为个人静态信息与近7天动态观测数据，输出未来7天与30天的多疾病风险概率。标签为未来窗口内是否发生疾病事件的二分类。

## 特征构建
- 静态特征来自人口统计学、既往病史、家族史、生物标志物与影像学标签
- 动态特征来自连续7天的生理指标、生活方式与环境暴露数据
- 动态特征按滑动窗口生成统计量：均值、标准差、最小、最大与趋势

## 基线模型
### XGBoost
适用于结构化特征，按疾病分别训练并共享同一套特征与预处理，输出可解释特征重要性。

### LSTM
适用于序列特征，输入为7天时间序列，静态特征在序列维度重复。

### Transformer
适用于时序建模，使用Transformer Encoder编码序列并输出多疾病并行概率。

## 校准
- XGBoost 使用 Platt Scaling
- LSTM 使用 Isotonic Regression
校准后输出保证在0-1区间并更接近真实发病率。

## 评估指标
AUROC、AUPRC、F1、Brier Score、Calibration Slope。

## 训练策略
按照时间排序划分训练集与测试集，训练集内部使用 TimeSeriesSplit 进行交叉验证，避免数据泄漏。
