# 特征列表

## 静态特征
- age（年龄）
- gender（性别）
- ethnicity（族群）
- education_years（受教育年限）
- socioeconomic_score（社会经济评分）
- atrial_fibrillation（房颤）
- previous_stroke（既往卒中）
- previous_tia（既往短暂性脑缺血发作）
- heart_disease（心脏病史）
- diabetes_years（糖尿病病程年数）
- hypertension_years（高血压病程年数）
- hypertension_controlled（高血压控制情况）
- chronic_kidney_disease（慢性肾病）
- peripheral_artery_disease（外周动脉疾病）
- family_stroke_history（卒中家族史）
- family_heart_disease（心脏病家族史）
- genetic_risk_score（遗传风险评分）
- carotid_plaque（颈动脉斑块）
- white_matter_lesions（白质病变）

## 动态特征
- systolic_bp（收缩压）
- diastolic_bp（舒张压）
- total_cholesterol（总胆固醇）
- hdl_cholesterol（高密度脂蛋白胆固醇）
- ldl_cholesterol（低密度脂蛋白胆固醇）
- triglycerides（甘油三酯）
- fasting_glucose（空腹血糖）
- hba1c（糖化血红蛋白）
- bmi（体重指数）
- waist_circumference（腰围）
- waist_hip_ratio（腰臀比）
- heart_rate（心率）
- alcohol_units_week（每周饮酒量）
- physical_activity_days（每周运动天数）
- mediterranean_diet_score（地中海饮食评分）
- sleep_hours（睡眠时长）
- crp（C反应蛋白）
- fibrinogen（纤维蛋白原）
- left_ventricular_ejection（左心室射血分数）
- avg_systolic_bp_24h（24小时平均收缩压）
- bp_variability（血压变异性）
- heart_rate_variability（心率变异性）
- daily_steps（日均步数）
- sleep_efficiency（睡眠效率）
- air_quality（空气质量）
- season（季节）

## 窗口统计量
每个动态特征生成以下统计量：
- mean_7d（7天均值）
- std_7d（7天标准差）
- min_7d（7天最小值）
- max_7d（7天最大值）
- trend_7d（7天趋势）

- parkinson（帕金森病）
