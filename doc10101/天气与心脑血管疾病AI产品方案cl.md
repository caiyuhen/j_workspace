## 摘要（Executive Summary）

大量流行病学证据表明，气温（尤其是低温与寒潮）、气温骤变、气压、湿度、空气污染与风寒等气象要素，与脑卒中、冠心病/急性心肌梗死、心律失常等心脑血管事件的发生率和死亡率显著相关。全球每年约有相当比例的心血管死亡可归因于非最适温度暴露。这为构建一款"天气—心脑血管风险"AI 产品提供了坚实的科学与市场基础。

本方案提出以"气象大数据 + 个体健康画像 + 深度学习风险模型 + 大模型/AI Agent 交互"为核心的智能产品体系，面向个人用户（可穿戴/APP）、医疗机构（医院/基层）、保险公司、政府疾控与气象部门、药械与养老企业提供分级风险预警与干预服务。

产品形态涵盖：C 端健康预警 APP/小程序与可穿戴插件、B 端 SaaS 风险平台与开放 API、G 端区域公共卫生预警大屏，以及嵌入医院/保险系统的 AI Agent 助手。

**收益预测（保守—中性情景，第 3 年）：** C 端订阅 + B/G 端 SaaS/API + 数据与保险分成合计年收入可达约 3,000 万—8,000 万元人民币，毛利率 55%–70%。详见第 7 章。

## 1. 天气与心脑血管疾病的关系（证据基础）

心脑血管系统对环境气象要素高度敏感。寒冷刺激引起交感神经兴奋、外周血管收缩、血压升高、血液黏稠度与凝血活性增加，从而诱发斑块破裂、血栓形成与脑血管痉挛；高温则通过脱水、血液浓缩、心脏负荷加重与电解质紊乱增加心血管风险。气温骤变、气压波动与空气污染进一步放大这些效应。

### 1.1 主要气象要素及其作用机制

| 气象要素 | 对心脑血管的主要影响 | 生理/病理机制 | 高风险人群 |
|---|---|---|---|
| 低温 / 寒潮 | 脑卒中、心梗、心衰急性加重风险↑；冬季死亡高峰 | 交感兴奋、血管收缩、血压↑、血黏度与凝血↑、斑块破裂 | 老年、高血压、冠心病、房颤患者 |
| 高温 / 热浪 | 心血管死亡、心律失常、心衰风险↑ | 脱水、血液浓缩、心率↑、心肌耗氧↑、电解质紊乱 | 老年、心衰、服利尿剂/降压药者 |
| 气温骤变（日温差、寒潮过境） | 48–72h 内卒中/心梗事件聚集 | 血压与血管张力剧烈波动、自主神经失衡 | 血压不稳、动脉硬化人群 |
| 气压变化 | 卒中、心梗发作时间聚集（部分研究） | 血氧、血管张力与凝血因子改变 | 冠心病、脑血管病患者 |
| 低湿/大风寒冷 | 心绞痛、心梗诱发（体感温度更低） | 风寒效应加剧血管收缩 | 户外活动老年人 |
| 空气污染（PM2.5、O₃，常与气象耦合） | 卒中、心梗、心律失常风险↑ | 系统性炎症、氧化应激、内皮功能障碍 | 全人群，慢病者更甚 |

### 1.2 关键量化证据（文献结论摘要）

| 研究 / 来源 | 样本 / 范围 | 核心结论（效应量） |
|---|---|---|
| Gasparrini A, et al. Lancet 2015（多国 384 地点 7,400 万死亡） | 13 国, 1985–2012 | 7.71% 的死亡可归因于非最适温度，其中低温（7.29%）远高于高温（0.42%） |
| Liu J, et al. Lancet Planetary Health 2022（Heat & CVD 系统综述 meta 分析） | 全球多研究汇总 | 高温每升高至热浪阈值，心血管疾病相关死亡与发病风险显著升高（合并 RR>1） |
| GBD 2021 Stroke Risk Factors. Lancet Neurol 2024 | 全球, 至 2021 | 2021 年现患卒中 9,380 万、新发 1,190 万；高/低温等环境因素为可归因风险因素之一 |
| Cold spell / 寒潮系列时间序列研究 | 中国、欧洲多城市 | 寒潮期间脑卒中入院与死亡显著上升，滞后效应可达数日至 2 周 |
| 气温骤降短期效应研究（case-crossover） | 多国 | 24–72h 内气温骤降与急性心梗、缺血性卒中发病风险升高相关 |

> **说明：** 上述为领域内广泛引用的代表性结论，具体效应量随地区、季节、人群与调整因素而异。完整引用与链接见第 9 章参考文献。

### 1.3 "温度—风险"关系的典型形态（文字化图形）

心脑血管风险与温度呈典型的非线性"U/J 形"曲线：在最适温度（MMT，多数地区约 20–25℃）附近风险最低；向低温端风险陡升（斜率大、滞后长），向高温端风险也升高（斜率较缓、滞后短）。

```
风险(RR)
高 │ *                                   *
   │  *                               *
   │   *                            *
   │     *                        *
   │        *                  *
   │            *          *
低 │                *  *（最适温度 MMT）
   └───────────────────────────────────► 温度
       低温(寒潮)      20–25℃      高温(热浪)
```

> **解读：** 产品的核心价值即在于对个体在此曲线上的位置、以及未来 24–72 小时的气象轨迹进行实时定位与预警。

## 3. 怎么做：技术实现路径

### 3.1 总体架构（分层）

- **① 数据层：** 气象数据（气温、气压、湿度、风、寒潮/热浪、空气质量、预报）＋ 个体健康数据（可穿戴、EHR/病历、体检、用药）＋ 区域流行病学数据（就诊/急救/死亡登记）。
- **② 特征与知识层：** 时空对齐、滞后效应特征（分布滞后非线性 DLNM）、体感温度/温差特征、个体慢病画像、医学知识图谱。
- **③ 模型层：** 深度学习风险模型（时序 + 表格 + 时空）＋ 统计流行病学模型（DLNM/时间序列）＋ 大模型（解读、问答、报告生成）。
- **④ 智能体层（AI Agent）：** 数据采集→风险计算→分级预警→个性化建议→随访闭环的自动化编排；工具调用（气象 API、EHR、消息推送）。
- **⑤ 应用层：** C 端 APP/小程序/可穿戴、B 端 SaaS/API、G 端预警大屏。

### 3.2 数据来源清单

| 数据类别 | 具体内容 | 来源 |
|---|---|---|
| 气象与环境 | 实况气温/气压/湿度/风、逐时预报、寒潮/热浪预警、PM2.5/O₃ | 气象局公开/商业 API、环境监测、ERA5 再分析 |
| 个体生理 | 心率、HRV、血压、血氧、活动、睡眠 | 智能手表、家用血压计、动态血压/心电 |
| 临床健康 | 诊断、用药、检验、既往史、体检报告 | 医院 EHR、区域健康档案、体检机构（合规授权） |
| 流行病学 | 急救出车、门急诊量、住院、死因登记 | 疾控/卫健/120（脱敏、政企合作） |
| 知识库 | 指南、文献、药品说明书 | 临床指南、PubMed、药典 |

### 3.3 建模方法

#### 3.3.1 深度学习风险模型

- 时序模型（LSTM/GRU/Temporal Fusion Transformer）：融合个体生理时序 + 未来气象序列，预测 24–72h 事件风险概率。
- 时空模型（Graph Neural Network / 时空 Transformer）：面向区域，预测各网格/城区未来就诊与事件强度。
- 表格/梯度提升（XGBoost/LightGBM）：基线慢病画像与静态风险分层，可解释性强，作为基线与特征筛选。
- 分布滞后非线性模型（DLNM）：刻画温度—风险的非线性与滞后（数天至两周），作为机理特征输入深度模型。
- 多模态融合：气象 + 生理 + 临床 + 空气质量联合表征，输出个体风险分（0–100）与置信区间。

#### 3.3.2 大模型与 AI Agent

- 大模型（LLM）：将风险分与医学知识转化为通俗、个性化的健康建议；解读体检/病历；多轮健康问答；自动生成医生随访清单与区域预警简报。
- RAG（检索增强）：绑定权威指南与本地知识库，降低幻觉，保证建议的循证性与可追溯（引用来源）。
- AI Agent 编排：定时拉取气象预报 → 计算个体/区域风险 → 触发分级预警 → 生成建议/名单 → 推送并登记随访 → 回收反馈闭环。

### 3.4 风险分级与干预策略

| 风险等级 | 触发条件（示例） | 系统动作 |
|---|---|---|
| 蓝色（低） | 风险分 <30，气象平稳 | 常规健康提示，日报 |
| 黄色（中） | 风险分 30–60，或 48h 内气温骤变>8℃ | 推送保暖/用药/减少晨练建议，提示监测血压 |
| 橙色（高） | 风险分 60–80，寒潮/热浪预警 | 强提醒 + 家属通知 + 建议就医评估，医生端进入随访名单 |
| 红色（极高） | 风险分 >80，多因素叠加 | 紧急提醒 + 急救指引 + 医生/120 联动预案 |

## 8. 风险、合规与壁垒

- **数据合规：** 个人健康信息与医疗数据须依法授权、脱敏、最小必要；遵循数据安全与个人信息保护相关法规。
- **医疗定位：** 定位为"健康风险预警与管理工具"，规避未经审批的诊断/治疗声明；如涉医疗器械功能需评估注册路径。
- **模型可信：** 以循证指南 + RAG 降低大模型幻觉，风险模型需本地化校准与前瞻性验证，提供可解释性。
- **科学严谨：** 温度—风险关系存在地区/人群异质性与滞后效应，须持续本地验证，避免过度承诺。
- **竞争壁垒：** 稀缺的"气象×健康×急救"多源数据闭环、临床验证与合作网络、本地化校准模型构成护城河。
