# CTMS Pro 临床试验管理系统部署指南本文档介绍如何使用 Docker 快速部署整个 CTMS Pro 系统，包含：前端、后端、PostgreSQL 数据库。## 部署前提条件确保您的服务器上已安装：- [Docker](https://docs.docker.com/get-docker/)- [Docker Compose](https://docs.docker.com/compose/install/)## 快速部署步骤1. **进入项目根目录**   在包含 `docker-compose.yml` 的项目根目录下打开终端。2. **一键启动服务**   执行以下命令，Docker Compose 会自动构建前端、后端镜像并拉取数据库镜像启动：   ```bash   docker-compose up -d --build   ```3. **查看服务状态**   ```bash   docker-compose ps   ```   你应该能看到三个容器（`ctms_db`、`ctms_backend`、`ctms_frontend`）都处于 `Up` 状态。4. **访问系统**   - **前端页面**：打开浏览器访问 `http://localhost:8899`   - **后端接口(Swagger API Docs)**：打开浏览器访问 `http://localhost:8898/docs`## 数据持久化与初始化- **数据库**：PostgreSQL 的数据会持久化挂载到项目根目录下的 `pgdata` 卷中。- **建库脚本**：首次启动 `db` 容器时，会执行 `docker/init-db.sh` 脚本自动创建 `ctms_pro` 数据库及 `ctms_user` 用户。- **表结构生成**：后端应用（FastAPI + SQLAlchemy）在启动时如果发现数据库为空，会自动执行表结构的创建（`create_all`）。您也可以根据实际需要导入现有的业务数据。## 日志查看如果您需要查看后端报错或访问日志，可执行：```bashdocker-compose logs -f backend```## 停止服务```bashdocker-compose down```*(注意：此命令不会删除挂载的数据库卷 `pgdata`，您的数据会安全保留。若需彻底清除数据可追加 `-v` 参数)*
