# 循证医学文献评价标准手册

## 1. 证据等级金字塔

### 1.1 治疗/预防/病因学研究
```
        ┌─────────────────┐
        │  系统评价/Meta   │  ← I级（最高）
        │     分析         │
        ├─────────────────┤
        │  随机对照试验    │  ← II级
        │     (RCT)        │
        ├─────────────────┤
        │  队列研究        │  ← III-1级
        ├─────────────────┤
        │  病例对照研究    │  ← III-2级
        ├─────────────────┤
        │  病例系列/报告   │  ← IV级
        ├─────────────────┤
        │  专家意见/经验   │  ← V级（最低）
        └─────────────────┘
```

### 1.2 诊断性研究
| 等级 | 研究设计 |
|------|----------|
| I | 与金标准盲法比较的横断面研究（连续病例） |
| II | 与金标准盲法比较的横断面研究（非连续病例） |
| III | 病例对照研究 |
| IV | 无明确金标准的诊断性研究 |

## 2. GRADE证据质量分级体系

### 2.1 证据等级定义

| 等级 | 符号 | 定义 | 含义 |
|------|------|------|------|
| 高 (High) | ⭫ | ⊕⊕⊕⊕ | 进一步研究不太可能改变对效应估计的确信度 |
| 中 (Moderate) | ⭬ | ⊕⊕⊕◯ | 进一步研究可能对效应估计有重要影响 |
| 低 (Low) | ⭭ | ⊕⊕◯◯ | 进一步研究很可能对效应估计有重要影响 |
| 极低 (Very Low) | ⭯ | ⊕◯◯◯ | 效应估计非常不确定 |

### 2.2 降级因素（5项）

| 因素 | 说明 | 降级条件 |
|------|------|----------|
| 偏倚风险 | 研究设计/执行缺陷 | RoB 2.0 评为"高风险" |
| 不一致性 | 结果异质性大 | I² > 50% 且无法解释 |
| 间接性 | PICO不直接匹配 | 人群/干预/对照/结局间接 |
| 不精确性 | 样本量小/置信区间宽 | 总样本量 < 400 或 CI 跨越无效线 |
| 发表偏倚 | 阴性结果缺失 | 漏斗图不对称 |

### 2.3 升级因素（3项，仅观察性研究）

| 因素 | 说明 | 升级条件 |
|------|------|----------|
| 大效应量 | 关联强度大 | RR > 2 或 < 0.5 |
| 剂量反应 | 暴露与结局梯度关系 | 存在统计学显著的剂量-反应趋势 |
| 混杂减弱 | 所有合理混杂均减弱效应 | 调整后效应更显著 |

### 2.4 推荐强度

| 强度 | 符号 | 表述 | 条件 |
|------|------|------|------|
| 强推荐 | 1 | "我们推荐..." | 利明显大于弊，证据质量高/中 |
| 弱推荐 | 2 | "我们建议..." | 利弊相当或证据质量低 |

## 3. 偏倚风险评估工具

### 3.1 Cochrane RoB 2.0（随机对照试验）

| 领域 | 评估问题 |
|------|----------|
| 随机化过程 | 随机序列产生是否充分？分配隐藏是否充分？ |
| 偏离既定干预 | 是否因干预分配而偏离？是否使用了恰当的分析方法？ |
| 缺失结局数据 | 各干预组缺失数据比例和原因是否相似？ |
| 结局测量 | 结局测量方法是否恰当？是否受干预分配影响？ |
| 选择性报告 | 是否按预先计划报告所有结局？ |

**判定**: 低风险 / 有些顾虑 / 高风险

### 3.2 NOS量表（队列/病例对照研究）
- 总分9星（选择4星 + 可比性2星 + 结局/暴露3星）
- ≥7星为高质量，5-6星为中等质量，≤4星为低质量

### 3.3 AMSTAR 2（系统评价）
- 16个条目，7个关键条目
- 总体置信度：高/中/低/极低

### 3.4 QUADAS-2（诊断准确性研究）
- 4个领域：病例选择、待评价试验、金标准、流程和时机
- 每个领域评估偏倚风险和临床适用性

## 4. 效应量指标说明

| 指标 | 全称 | 适用场景 | 解释 |
|------|------|----------|------|
| RR | 相对危险度 (Risk Ratio) | 队列研究/RCT | RR>1表示暴露增加风险 |
| OR | 比值比 (Odds Ratio) | 病例对照研究 | OR>1表示暴露与疾病正相关 |
| HR | 风险比 (Hazard Ratio) | 生存分析 | HR>1表示干预组事件风险更高 |
| MD | 均数差 (Mean Difference) | 连续变量 | MD>0表示干预组均值更高 |
| SMD | 标准化均数差 | 不同量表合并 | 0.2小/0.5中/0.8大 |

### 4.1 置信区间解读
- 95%CI 不跨越无效线（RR的1，MD的0）→ 统计学显著
- CI 宽度 → 估计精确度，CI越窄越精确
- 如果CI跨越临床决策阈值 → 需讨论临床意义

## 5. 异质性评估

### 5.1 I²统计量
| I² 值 | 异质性程度 | 处理建议 |
|-------|-----------|----------|
| 0-25% | 低 | 使用固定效应模型 |
| 25-50% | 中 | 使用随机效应模型 |
| 50-75% | 高 | 探索异质性来源（亚组分析/Meta回归） |
| 75-100% | 极高 | 不推荐合并，改为叙述性综合 |

### 5.2 Cochran's Q检验
- P < 0.10 → 存在显著异质性

---

## 6. 发表偏倚检测

### 6.1 漏斗图（Funnel Plot）
- 对称 → 无显著发表偏倚
- 不对称 → 可能存在发表偏倚

### 6.2 Egger's 检验
- P < 0.05 → 存在显著发表偏倚

### 6.3 处理策略
- 纳入文献<10篇 → 不进行漏斗图分析（检验效力不足）
- 发现发表偏倚 → 讨论其对结论的影响

## 7. 检索策略规范

### 7.1 必检数据库
| 数据库 | 覆盖范围 | 优先级 |
|--------|----------|--------|
| PubMed/MEDLINE | 生物医学综合 | 必检 |
| Embase | 欧洲/药学重点 | 强烈推荐 |
| Cochrane Library | 系统评价/RCT | 必检 |
| Web of Science | 跨学科 | 推荐 |
| CNKI | 中文文献 | 中文综述必检 |
| 万方 | 中文文献 | 中文综述必检 |

### 7.2 检索式构建步骤
1. PICO拆解 → 核心概念词汇
2. 每个概念：MeSH词 + 自由词（同义词/近义词/拼写变体）
3. 同概念内词用 OR 连接
4. 不同概念间用 AND 连接
5. 必要时使用 NOT 排除

### 7.3 PubMed检索式示例
```
("Diabetes Mellitus, Type 2"[MeSH] OR "type 2 diabetes"[tiab] OR "T2DM"[tiab])
AND
("Sodium-Glucose Transporter 2 Inhibitors"[MeSH] OR "SGLT-2"[tiab] OR "dapagliflozin"[tiab] OR "empagliflozin"[tiab])
AND
("Cardiovascular Diseases"[MeSH] OR "MACE"[tiab] OR "heart failure"[tiab] OR "cardiovascular outcome"[tiab])
AND
("Randomized Controlled Trial"[ptyp] OR "Meta-Analysis"[ptyp])
AND
("2015"[Date - Publication] : "2025"[Date - Publication])
```

## 9. 常见统计陷阱

1. **生态学谬误**: 将群体水平的关联推论到个体
2. **辛普森悖论**: 分组趋势与总体趋势相反
3. **多重比较**: 未校正的多次检验增大I类错误
4. **依从性偏倚**: 未使用ITT分析
5. **选择性报告**: 仅报告显著结果
6. **p值误解**: p>0.05 ≠ "无差异"，可能是检验效力不足
