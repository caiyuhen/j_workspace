# 脊柱侧弯干预手段与数字孪生模拟原理 (Intervention Methods & Simulation Logic)

本文档详细介绍了当前数字孪生系统 (`simulate_treatment.py`) 支持的脊柱侧弯干预手段，以及这些手段如何在算法中被模拟。

## 1. 主要干预手段 (Intervention Types)

目前系统主要支持以下四种干预模式：

### A. 脊柱矫形支具 (Orthotic Brace)
*   **适用人群**: 生长发育期的青少年特发性脊柱侧弯 (AIS)，Cobb 角通常在 20°-45° 之间。
*   **原理**: 通过施加外部的三点力学矫正力，限制脊柱的侧向弯曲和旋转，引导脊柱在生长过程中向正确方向发展。
*   **常见类型**: 波士顿支具 (Boston), 密尔沃基支具 (Milwaukee), 色努支具 (Chêneau)。
*   **关键因素**: 
    *   **佩戴时长**: 每天建议 18-23 小时。
    *   **依从性 (Compliance)**: 患者实际佩戴时间与建议时间的比例。

### B. 特定物理治疗 (Specific Physical Therapy / PSSE)
*   **适用人群**: 轻度侧弯 (<20°)，或作为支具治疗的辅助手段。
*   **原理**: 通过特定的肌肉训练（如 Schroth 施罗斯疗法），增强脊柱周围肌肉的非对称性力量，改善姿态控制。
*   **关键因素**: 
    *   **训练频率**: 每周训练次数。
    *   **动作准确性**: 是否正确执行了特定的呼吸和肌肉收缩动作。

### C. 强化综合干预 (Intensive Rehabilitation)
*   **适用人群**: 中重度侧弯，或希望短期内获得明显改善的患者。
*   **原理**: 结合高强度全日制支具（23小时/天）与每日密集的施罗斯强化训练（2-3小时/天）。通过最大化机械矫正力与主动肌肉控制的协同作用，打破脊柱畸形的恶性循环。
*   **模拟效果**: 
    *   **矫正力度**: 极高。
    *   **改善潜力**: 可显著减少 Cobb 角，甚至在生长期实现部分逆转。

### D. 自然观察 / 无干预 (Observation / Natural History)
*   **适用人群**: 极轻度侧弯 (<10-15°)，或骨骼已成熟且侧弯稳定的患者。
*   **风险**: 在生长高峰期（Risser 征 0-2级），侧弯有快速恶化的风险。

## 2. 数字孪生模拟算法 (Simulation Algorithm)

在我们的 Python 脚本中，干预效果通过以下参数进行量化模拟：

### 输入参数 (Input Parameters)
在 `simulate_treatment.py` 中，通过 `treatment_plan` 字典配置：

```python
plan = {
    'type': 'Brace',       # 干预类型: 'Brace', 'PT', 'None'
    'duration': 24,        # 持续时间 (月)
    'compliance': 0.9      # 依从性 (0.0 - 1.0), 1.0 代表 100% 配合
}
```

### 模拟逻辑 (Simulation Logic)

系统采用**月度迭代**的方式计算脊柱形态的变化：

#### 1. 自然进展率 (Natural Progression Rate)
*   假设在无干预且处于生长高峰期的情况下，Cobb 角每月恶化 **0.5°**。
*   *代码实现*: `natural_worsening_rate_deg = 0.5`

#### 2. 干预修正率 (Intervention Correction Rate)
干预手段会产生一个“负向”的角度变化（即改善），其效果受**依从性**系数影响。

| 干预手段 | 基础改善率 (每满分依从性) | 实际改善计算公式 |
| :--- | :--- | :--- |
| **支具 (Brace)** | **-0.8° / 月** | `correction = -0.8 * compliance` |
| **理疗 (PT)** | **-0.3° / 月** | `correction = -0.3 * compliance` |
| **强化干预 (Intensive)** | **-1.5° / 月** | `correction = -1.5 * compliance` |
| **无 (None)** | **0° / 月** | `correction = 0` |

#### 3. 净效果计算 (Net Effect)
每月最终的角度变化 = `自然进展率` + `干预修正率`

*   **例子 (支具, 90% 依从性)**:
    *   自然恶化: +0.5°
    *   支具修正: -0.8° * 0.9 = -0.72°
    *   **净变化**: +0.5° - 0.72° = **-0.22° / 月** (即每月改善 0.22度)

*   **例子 (支具, 50% 依从性 - 偷懒)**:
    *   自然恶化: +0.5°
    *   支具修正: -0.8° * 0.5 = -0.4°
    *   **净变化**: +0.5° - 0.4° = **+0.1° / 月** (尽管戴了支具，但因时间不足，侧弯仍在缓慢加重)

### 4. 三维形态映射
除了 Cobb 角（冠状面），系统还会同步调整：
*   **矢状面 (Kyphosis/Lordosis)**: 假设干预能改善 50% 的矢状面异常。
*   **椎体旋转 (Vertebral Rotation)**: 旋转的改善通常滞后于角度，设定为角度改善率的关联函数。

## 3. 未来扩展方向

目前的算法基于简化的生物力学模型。未来可引入更复杂的参数：
1.  **生长潜能参数**: 引入 Risser 征或 Sanders 分级，动态调整“自然进展率”。
2.  **有限元分析 (FEA)**: 基于真实的椎体 3D 网格进行力学仿真，而非简化的几何推演。
3.  **肌肉骨骼模型**: 模拟肌肉力量对脊柱稳定性的影响。
