# 干预与治疗方法模型 (Intervention Methods)

本文档描述了模拟引擎中使用的各种干预方法的数学假设和逻辑。

## 1. 观察 (Observation / Natural History)
*   **适用场景**: 轻度侧弯 (< 25°) 或生长已停止的患者。
*   **模拟逻辑**:
    *   如果是生长期 (年龄 < 18): 假设自然进展率为 **+5° / 年** (恶化)。
    *   如果是成熟期: 假设稳定，变化率为 0。

## 2. 支具治疗 (Brace Treatment)
*   **适用场景**: 中度侧弯 (25° - 45°)，且处于生长期。
*   **关键参数**: 依从性 (Compliance, $C$)。
*   **模拟逻辑**:
    *   基础矫正率: $R_{base} = -2.0^\circ$ / 年 (改善)。
    *   依从性修正:
        *   如果 $C \ge 0.8$ (每天 > 18小时): 有效矫正，使用 $R_{base}$。
        *   如果 $0.5 \le C < 0.8$: 效果减弱，变化率 $\approx 0$ (维持)。
        *   如果 $C < 0.5$: 治疗无效，按自然进展处理 (+3° 到 +5° / 年)。

## 3. 手术治疗 (Surgery)
*   **适用场景**: 重度侧弯 (> 45°)。
*   **模拟逻辑**:
    *   **即时矫正**: 在手术实施的时间点（通常是第 0-2 个月），Cobb 角迅速下降至目标值（通常 < 10°）。
    *   **术后稳定**: 术后角度保持稳定，融合区域不再生长或弯曲。
    *   **模型实现**: 这是一个阶跃函数或快速的线性下降，随后保持恒定。

## 4. 模拟时间分辨率 (Simulation Resolution)

*   **时间步长**: 1 周 (Week)
*   **转换逻辑**: 输入的持续时间（月）将乘以 4 转换为周数。
*   **平滑处理**: 年增长率被除以 52 以分配到每周的变化中，确保演变曲线的平滑性。
