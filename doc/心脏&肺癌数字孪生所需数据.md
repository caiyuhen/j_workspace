# 心脏数字孪生所需数据

### 一、 基础解剖结构数据 (几何数据)

这是虚拟心脏的“蓝图”，定义了心脏的物理形态和空间结构。

1. **心血管系统影像：**
   - **CT** 
   - **MRI **
   - **超声心动图 **
2. **血管造影数据** 
3. **组织学数据**

### 二、 生理与功能数据 (动态数据)

这是让静态几何模型“动”起来的关键，描述心脏如何工作。

1. **电生理数据：**
   - **12导联心电图** 
   - **心内电生理标测数据** 
2. **血流动力学数据：**
   - **血压**
   - **心输出量和射血分数 (EF)**
   - **肺动脉楔压 (PCWP) 等心内压力数据** 
3. **生化与分子标记物：**
   - **脑钠肽 (BNP) / N末端前脑钠肽 (NT-proBNP)** 
   - **肌钙蛋白 (Troponin)** 
   - **电解质水平** 
   - **血糖、血脂等代谢指标** 

### 三、 患者个体化数据

这些数据将通用模型转化为“个人专属”的孪生体。

1. **人口统计学和临床病史：** 
   - 年龄
   - 性别
   - 身高
   - 体重
   - 血压病史
   - 糖尿病史
   - 冠心病史
   - 心力衰竭史
   - 卒中史。
2. **生活方式：** 
   - 吸烟
   - 饮酒
   - 运动习惯。
3. **用药记录** 
4. **基因数据** 

### 四、 实时/连续监测数据

这是数字孪生从“模拟”走向“实时监控和预警”的关键。

1. **可穿戴设备数据（选填）**
   - **智能手表/手环** 
   - **其他医疗级可穿戴** 
2. **植入式设备数据**
   - **起搏器、ICD (植入式心律转复除颤器) 数据** 



# 肺癌数字孪生所需数据

### 一、 肿瘤的解剖学与影像数据

这是构成数字孪生三维虚拟结构的“物理基础”，提供了肿瘤的形态、位置和大小等静态信息。

1. **高分辨率CT扫描影像:**
   - **CTA** 
   - **CT** 
2. **PET-CT (正电子发射计算机断层显像):**
   - **代谢活性** 
   - **淋巴结和远处转移评估** 
3. **MRI (磁共振成像):**
4. **病理切片与数字病理**

### 二、 肿瘤的分子与遗传学数据

这是揭示肿瘤“驱动基因”和“弱点”的“软件代码”，是实现精准医疗和靶向治疗的关键。

1. **基因组学数据 (从组织样本中获取):**
   - **目标基因检测**
   - **全外显子/基因组测序** 
2. **蛋白质组学与免疫组化:**
   - **PD-L1表达水平** 
   - **肿瘤突变负荷 (TMB)** 
   - **其他蛋白标志物** 
3. **转录组学数据**

### 三、 患者个体化与生理数据

这些数据描述了患者自身的状况和身体状况，这对于评估治疗的耐受性、风险和综合决策至关重要。

1. **人口统计学与临床病史:**
   - 年龄
   - 性别
   - 身高
   - 体重
   - **吸烟史 ( quantity and pack-years )** 
   - 既往病史，特别是心肺功能相关的疾病（如COPD、哮喘）。
2. **心肺功能测试:**
   - **肺功能检查 (PFT)**
   - **6分钟步行试验**
3. **血液实验室检查 (外周血):**
   - **血常规 (CBC)** 
   - **肿瘤标志物** 
   - **炎症指标** 如 **CRP (C-反应蛋白)**、D-二聚体，反映身体的炎症
